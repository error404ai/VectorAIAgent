# Getting Started with BrowseAI

## Overview

BrowseAI is a powerful desktop browser automation tool that allows you to automate web browsing tasks using natural language commands and scripts.

## Installation

### Requirements
- Operating System: Windows 10+, macOS 10.14+, or Linux (Ubuntu 20.04+)
- RAM: 4GB minimum, 8GB recommended
- Disk Space: 500MB

### Download

Download the latest version from our [releases page](https://github.com/error404ai/VectorAIAgent/releases).

### Installation Steps

**Windows:**
1. Download the `.exe` installer
2. Run the installer and follow the on-screen instructions
3. Launch BrowseAI from the Start Menu

**macOS:**
1. Download the `.dmg` file
2. Open the file and drag BrowseAI to Applications
3. Launch from Applications folder

**Linux:**
1. Download the `.AppImage` file
2. Make it executable: `chmod +x BrowseAI.AppImage`
3. Run: `./BrowseAI.AppImage`

## Quick Start

1. Launch BrowseAI
2. Create a new automation profile
3. Enter your automation commands in natural language
4. Watch as the browser executes your tasks automatically
